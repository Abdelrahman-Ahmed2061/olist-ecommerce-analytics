
# Olist E-Commerce Sales & Customer Experience Analytics

## Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset by Olist to
understand sales performance, customer behavior, delivery performance,
product trends, and seller performance.

The project aims to transform raw e-commerce data into meaningful business
insights that support data-driven decision-making.

Using Microsoft Power BI, the team will clean and transform the data,
develop a structured data model, create interactive dashboards, and provide
actionable business recommendations.

## Problem Statement

E-commerce businesses need to understand their sales performance, customer
experience, and delivery operations to identify improvement opportunities.

This project uses Olist's historical e-commerce data to investigate
business performance, identify patterns, and highlight areas that may
require operational improvements.

## Project Objectives

- Analyze sales performance and revenue trends.
- Understand customer purchasing behavior.
- Evaluate delivery performance and identify delayed orders.
- Analyze customer review scores and satisfaction patterns.
- Identify high-performing product categories.
- Analyze seller performance and geographic distribution.
- Explore relationships between delivery performance and customer reviews.
- Build interactive dashboards for business analysis.
- Provide data-driven insights and recommendations.

## Dataset

**Dataset Name:** Brazilian E-Commerce Public Dataset by Olist

The dataset contains multiple related tables covering e-commerce orders,
customers, products, sellers, payments, reviews, and geographic information.

### Data Tables

- Customers
- Geolocation
- Order Items
- Order Payments
- Order Reviews
- Orders
- Products
- Product Category Translation
- Sellers
